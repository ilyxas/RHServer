## Следствие для кода

- `rh_core.journal.Journal`: строка = канонический JSON (RFC 8785), поле `prev` = sha256 предыдущей строки, первая запись — 64 нуля; цепочка идёт через границы файлов в порядке имён.
- Если часы или часовой пояс сдвинулись назад, запись идёт в последний (более поздний) файл, а не в старый: иначе порядок имён разошёлся бы с порядком записей.
- `rhcore journal verify` ловит правку, удаление, перестановку и мусор в любой строке. Обрезку последних строк цепочка сама по себе не ловит; это ограничение записано здесь и в PR.
