# Решения по [проверить]

Одна запись на пункт: `NNN-<тема>.md`.

```
# NNN. <вопрос>

- Пункт SPEC: §…
- Дата: YYYY-MM-DD
- Вывод: …
- Источник: ссылка на документацию / код / вывод команды на Mac
- Следствие для кода: …
```

Если вывод расходится с SPEC — запись со статусом «ждёт Илью», реализация по этому направлению стоит.
